# Kumarites | Group 7 - A3101

## Overview

**Kumarites** is a community-based web platform designed to help users discover **sulit finds, store recommendations, promotions, and products**. The website allows users to browse trending stores, explore buzzes, and share useful recommendations with the community.

## Main Pages

* **Home** – Displays featured content and trending stores.
* **Buzz Feed** – Shows community posts, recommendations, deals, and useful finds.
* **Stores** – Allows users to explore featured stores and their information.
* **Categories** – Organizes buzzes and stores by category.
* **Log In / Sign Up** – Provides account access and registration.

## Technologies Used

* CSS
* JavaScript
